# Голосовые записи — выезд 1 (текст для озвучки)

Три записи лежат на уровне (диктофоны). Пока голос не записан, вместо него тихие помехи, реплики идут субтитрами.

**Как вставить запись:**
1. Сохраните файл (wav или mp3) с именем `VoiceLog_Security`, `VoiceLog_WorkRoom` или `VoiceLog_Records`.
2. Положите его в папку `conent` и скажите Claude «вставь голосовые».
3. Claude импортирует файл и пропишет слот звука.

После этого игра сама возьмёт ваш звук вместо помех.

**Тайминг:** реплики показываются по очереди. Каждая держится на экране примерно 1 секунду на 15 букв (минимум 2.5 с), между репликами 0.3 с паузы. Читайте спокойно, с паузой ~0.5 с между репликами. Перед первой репликой 0.8 с тишины: это щелчок кнопки.

**Обработка:** голос как из старого диктофона. Чуть приглушить верха и добавить лёгкое шипение плёнки. Без музыки.

## VoiceLog_Security — ночная смена (охранник, мужчина 50+, устало, буднично)

1. Журнал смены. Двадцать три сорок. Обход второго этажа закончил, всё закрыто.
2. В серверной опять гудят вентиляторы. Питание с неё сняли ещё в понедельник — я сам видел, как опечатывали щит.
3. Позвонил дежурному инженеру. Сказал — остаточный ток, конденсаторы. Ну, ему виднее.
4. Свет в коридоре моргает, лампы менять не будут — здание всё равно списывают. Батарейки для фонаря оставлю в техпомещении.

## VoiceLog_WorkRoom — инженер (мужчина или женщина 30–40, деловито, под конец немного неуверенно)

1. Заметка для себя. Сверка архива перед списанием, стойка в серверном секторе.
2. По описи сорок файлов. На диске — сорок один. Лишний без номера задания, дата создания — сегодняшняя ночь.
3. Скорее всего, остаток с прошлой инвентаризации, а дата сбилась при перезапуске. Завтра пересчитаю.
4. И пусть кто-нибудь проверит предохранители на щите. Один уже сгорел, когда я включал стойку.

## VoiceLog_Records — делопроизводитель (женщина 40–55, тихо, сдержанно, в конце — тревога)

1. Напоминание. Дату списания опять перенесли — третий раз за месяц. Причину не называют.
2. Автоответчик в холле теперь говорит мне «доброй ночи». По имени. Я его так не настраивала.
3. Наверное, кто-то из техников пошутил. Записала в журнал, пусть разбираются.
4. Ключи от архива оставляю на посту охраны. Больше я сюда по ночам не прихожу.

Тексты меняются в `Content/Localization/ST_UI.csv` (ключи `VoiceLog_*`). Английская версия лежит в `ST_UI_EN.csv`.
