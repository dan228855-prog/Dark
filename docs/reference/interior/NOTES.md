# Разбор референсов интерьера (07.10.2026)

Бриф: `docs` — файл пользователя «INTERIOR REFERENCE PACK 10/10» (НИИ конца 80-х—90-х, заброшен, но не разрушен).
Фото — ссылки на Wikimedia (в архиве только gallery.html/README.md).

## Полезные
- **Коридор НИИ Радио 1981** — https://russiainphoto.ru/photos/332334/ — сводчатый высокий потолок, двустворчатые филенчатые двери, стенд «Лучшие по производству» с фото, длинные деревянные скамьи у стены, паркет, светлые стены.
- **Grungy corridor of abandoned school** (Commons) — двухтонная покраска (тёмно-зелёный низ ~1.4 м / светлый верх), ряд высоких окон, голая лампа на проводе.
- **Secret Soviet Bunker Office, Ligatne** (Commons) — красное лакированное дерево, зелёная настольная лампа, 3 дисковых телефона, кресло, обои.
- **BBC Soviet workstation 1987** — https://c.files.bbci.co.uk/8B2E/production/_104003653_3-1.jpg — бежевый терминал (экран + корпус), массивная клавиатура, записка на мониторе.
- **BESM-6 Politech Museum** (Commons) — стойки П-образно, сине-белые корпуса, пульт с наклонной панелью и деревянным подлокотником, лотки под потолком.
- **BESM-6 stoika n**, **ES-1052 Control Unit**, **Console BESM-6 CU** (Commons) — ячейки, тумблеры, стрелочный прибор, табличка «ЕС 1052».
