# База D.A.R.C. — межуровневый коридор (ТЗ)

Решение автора от 07.10.2026 + мастер-документ (разд. 7, 31, 32, 102, 108, 112.9–112.10, мета-блок 5–6) + `DARC_vertical_slice.md` (разд. 9).
Карта: `/Game/DARC/Maps/BaseMap` (собирается скриптом `Tools/darc_build_base.py`, как здание уровня 1).

## Идея
База — постоянная точка между выездами: **База → Выезд → База**. Она стабильна, чтобы игроки замечали мелкие изменения
(переложенный предмет, новый экран, свет под дверью). Не старое советское здание, как на выездах, а **современный дорогой бункер**:
серые тона, стены из полированных мраморных плит, ровный холодный свет, чистота. Контраст с выездами — часть подачи.

## Планировка (прямая, без развилок)
```
[ ВЪЕЗД / ворота ] ГАРАЖ (машина)  →  КОРИДОР ~60 м, двери по обе стороны  →  ТУПИК
```
- **Гараж** ~14 × 12 м, высота 5 м: машина, ворота въезда (закрыты, декорация), шлагбаум/разметка, стеллажи.
  Игрок появляется у машины, как будто только что из неё вышел (точки появления у дверей машины, по одной на игрока, до 5).
- **Коридор** ~60 × 4 м, высота 3.5 м: мраморные стены, потолочные световые линии, динамики под потолком, номера на дверях.
- **Тупик** — глухая стена с логотипом D.A.R.C. и последней дверью (см. «дверь со светом»).

## Двери и комнаты
Открыта с самого начала только **R1 — первая дверь справа**. Остальные заперты: одни открываются по прогрессу кампании
(факт в WorldMemory → `ADarcBaseUnlock` отпирает дверь), другие не откроются никогда (атмосфера, «у корпорации есть секреты»).

| Дверь | Комната | Когда открывается | Что внутри / зачем |
|---|---|---|---|
| R1 | **Лобби куратора** | сразу | Стойка, кресло с манекеном за тонированным стеклом (лица не видно), динамики, экран с логотипом. Куратор говорит **только через динамики этой комнаты**. Здесь выдаётся задание и принимаются данные. |
| L1 | **Комната отдыха** | после 1-го выезда (`Base.RestRoom`) | Диван, кофемашина, телевизор, **котёнок** (спит, уходит, подходит; не скример). |
| R2 | **Архив** (архивный терминал) | `Base.ArchiveTerminal` — успешный срез с архивом | Первое улучшение по срезу: терминал с найденными записями, логами, «сухими» записями о смертях. |
| L2 | **Снаряжение** | после 2-го выезда (`Base.Equipment`) | Шкафчики, стенд с инструментами (лом, ключ, тестер, рация): выбор того, что взять на выезд. |
| R3 | **Хранилище находок** | после 3-го выезда (`Base.Evidence`) | Стеллажи под номерами: предметы, вывезенные с выездов (последствия видны на базе). |
| L3 | **Переговорная** | после 4-го выезда (`Base.Briefing`) | Стол, проектор, схемы объектов — «обсуждение событий» (разд. 31). |
| R4 | **Медпункт** | после 5-го выезда (`Base.Medbay`) | Кушетка, аптечки — к теме смертей и эскалации. |
| L4–L5, R5 | служебные: «Техническое», «Серверная D.A.R.C.», «Посторонним вход воспрещён» | никогда | Заперты всегда. Табличка, считыватель карт с красным огоньком. |
| L6 | **Дверь со светом** (у тупика) | **никогда в 1-й арке** | Из-под порога периодически мерцает свет. После 7-го уровня — свет постоянный, за дверью тихий гул и вентилятор, при приближении гул смолкает (разд. 102). |
| R6 | пустая запертая | позже (резерв под будущие улучшения) | — |

Названия фактов — рабочие; выдаёт их `UDarcMissionDefinition::CampaignFactsOnSuccess` соответствующего выезда.

## Сценарий визита
1. Загрузка → игрок у машины в гараже.
2. Идёт в коридор, открыта только R1. В лобби (триггер входа) куратор из динамиков выдаёт задание; реплики — субтитры через `ADarcGameState::Say`, тексты — ST_UI.
   Поведение куратора по уровням — разд. 108 (1–2: коротко и по делу; 3: «ничего необычного?»; 4: отрицает; 5: молча выдаёт; 6: пауза; 7: процедура ломается).
3. После выдачи задания задача на экране: «Вернуться к машине». Машина до этого не реагирует.
4. У машины — **E: сесть**. Каждый игрок садится сам; когда сели все живые — затемнение и переезд на карту выезда (для кооператива — переезд всего сервера).
5. После выезда — снова база, у машины: куратор принимает данные («Получили?» — «Да.» — «Хорошо.» — пауза — «Следующее задание получите позже.»),
   открываются новые двери по фактам, видны последствия (лишний файл в архиве, «плановое обслуживание сети» после блэкаута).

## Выбор объекта (терминал в лобби)
- В лобби у боковой стены — терминал «Объекты» (E). Список выездов 1–7:
  пройденные — «повторить», следующий по сюжету — «следующий», дальше — «ЗАСЕКРЕЧЕНО» (кнопка неактивна).
- По умолчанию выбран следующий по сюжету. Выбор сервер проверяет (игрок у терминала, уровень открыт),
  виден всем на экране над стойкой (`ОБЪЕКТ N / название`), куратор отвечает репликой («Повторный выезд. Принято.»).
- Машина везёт на выбранный объект. Если следующий уровень ещё не сделан — выбран последний пройденный, куратор говорит, что новых объектов нет.
- Список выездов, карты, реплики и факты — `Config/DefaultGame.ini`, секция `[/Script/DARK.DarcBaseCurator]`.

## Мелочи для «точки сравнения» (разд. 32)
- Дозированные изменения между визитами: кружка на другом месте, новый экран на терминале, сообщение в динамике.
- Динамики в коридоре иногда дают короткий шум/щелчок (списывается на технику).
- Никаких скримеров на базе.

## Техническое
- Сборка карты — скрипт (стены, пол, потолок, двери, свет, точки появления), пропсы — руками автора в отдельной папке, как на уровне 1.
- Двери — `AInteractableDoor` (`bIsLocked`), разблокировка — `ADarcBaseUnlock` с `RequiredFact`.
- Машина базы — новый актор (сесть по E, переезд, когда сели все).
- Материал стен: полированный мрамор (нужна текстура CC0, например Poly Haven); до этого — серый глянцевый материал.
- Меню «Играть» ведёт на базу, а не сразу на 1LvlMap. После выезда (успех или провал) — затемнение и переезд на базу (`DarcGameMode.BaseMap`).

## Сделано (07.10.2026)
Карта `BaseMap` собрана скриптом, проверено в Play: появление у машины → лобби → куратор выдаёт задание (субтитры) → машина → 1LvlMap → конец выезда → база → куратор принимает данные → открылась комната отдыха (L1).
Не проверено: окно выбора объекта (клик), кооператив (посадка нескольких игроков), створки дверей при открытии. Мрамор — пока серый глянцевый материал.
