# Что сделать за компьютером (один раз)

Всё остальное подготовлено в репозитории. От тебя — 5 шагов. Если на каком-то шаге ошибка, сделай скриншот или скопируй текст ошибки и пришли Claude.

## 1. Забрать свежую версию из GitHub

В папке проекта (через GitHub Desktop или командой `git pull`).

## 2. Положить скачанные файлы в `RawAssets`

В корне проекта (рядом с `DARK.uproject`) создай папку `RawAssets` и разложи файлы:

```
RawAssets/
  Meshes/          ← модели: .fbx .obj .gltf .glb (можно своими подпапками: Doors/, Props/ …)
  Textures/        ← текстуры: .png .jpg .exr .hdr (наборы Poly Haven/ambientCG — как скачались)
  Sounds/          ← звуки: .wav .ogg .flac .mp3
  Sounds/Loops/    ← зацикленные звуки: гул ламп, генератор, фон леса/серверной
```

- **Архивы (.zip/.rar) распакуй**, скрипт их не открывает.
- **Названия файлов любые**, скрипт сам сделает правильные имена.
- **То, что уже импортировано в проект** (паки из Fab, сам шаблон), класть не нужно, скрипт их тоже увидит.
- **В GitHub эта папка не попадает**, она в `.gitignore`.

## 3. Собрать проект

1. Правой кнопкой по `DARK.uproject` → **Generate Visual Studio project files**.
2. Открыть `DARK.sln` → вверху выбрать **Development Editor** → **Build** (Ctrl+Shift+B).
   Или просто открыть `DARK.uproject`: UE спросит «пересобрать модули?» → **Да**.
3. **Если сборка упала:** в Visual Studio окно **Output** (Вывод) → скопировать всё → прислать Claude. Это нормально: код ни разу не компилировался, исправления займут пару кругов.

## 4. Запустить скрипт настройки

В редакторе: меню **Tools → Execute Python Script…** → выбрать `Tools/darc_setup.py`. Скрипт:
- создаст карту среза;
- импортирует всё из `RawAssets` и соберёт материалы из наборов текстур;
- импортирует таблицы задач и событий;
- запишет список всех ассетов проекта в **`docs/asset_inventory.csv`**.

В конце появится окно с отчётом. Скрипт можно запускать повторно, например после того как докачаешь новые файлы.

## 5. Отправить список и поиграть

1. **Запушить `docs/asset_inventory.csv`** в GitHub (или прислать файл в чат). По нему Claude впишет в `Config/DefaultGame.ini`, какая модель, материал и звук куда, без твоих кликов. После этого достаточно ещё раз сделать `git pull`.
2. **Открыть карту** `Content/DARC/Maps/L_Slice` (она же откроется при запуске) → **Play**.
   - **Соло:** просто Play.
   - **Кооп на одном компьютере:** стрелка рядом с Play → **Number of Players: 2**, **Net Mode: Play As Listen Server**.

## Управление в срезе

| Клавиша | Что делает |
|---|---|
| WASD, мышь, пробел | как в шаблоне |
| **E** | взаимодействие: взять/положить предмет в руку, дверь, щиток, терминал, закрепить кабель |
| **ЛКМ (держать)** | схватить физический объект (стойку, генератор, шкаф, предмет на полу) и тащить; отпустить ЛКМ — отпустить |
| **ПКМ** | пока держишь — толкнуть/бросить (тяжёлое только толкается) |
| **Tab** | показать/скрыть список задач |
| **Enter / Esc** | в окне терминала: отправить код / выйти |
| После гибели (дух) | WASD, пробел/Ctrl — полёт; **ЛКМ** — мигнуть светом; **F** — рубильник; **ПКМ** — толкнуть предмет |

Пока ассеты не подключены, всё будет серыми коробками. Так и задумано, игра уже проходится.

Звуки тела (шаги, прыжок, приземление) — слоты `Footstep_<Поверхность>` (Concrete, Tile, Metal, Wood, Carpet, Dirt, Grass), запасной `Footstep`, `Jump`, `Land`. Поверхность определяется по имени материала пола (`M_metal_plate` → Metal, `M_floor_tiles_02` → Tile, асфальт/бетон → Concrete). Несколько вариантов одного звука — слоты `Имя`, `Имя_1` … `Имя_8`, играется случайный (работает для любого слота). Все звуки без своих настроек затухания теперь объёмные: громко в 3 м, затихают к ~30 м.

## Как пройти срез (для проверки)

1. Подойти к охраннику у будки (он заговорит) → **E**: он отдаст карту доступа. На карте 4 цифры кода.
2. В здании: рабочая комната (север коридора) → терминал → ввести код с карты.
3. Серверная в конце коридора заперта:
   - **считыватель** у двери: E с картой в руках;
   - **или кодовая панель**: код написан на табличке в кладовой (юг коридора).
4. Питание сервера:
   - **щит в коридоре**, щиток `Server`: выключить рубильник → вставить предохранитель (лежит у щита) → включить;
   - **или генератор** из кладовой: тащить **ЛКМ** к вводу в серверной (в коопе один не сдвинет — берутся двое; в соло сил хватает одному) → E на вводе.
   - Если вставить предохранитель при **включённом** рубильнике, он сгорит, и в коридоре погаснет свет. Запасной предохранитель лежит на шкафу в кладовой.
5. Стойку в серверной перетащить **ЛКМ** к рабочей точке — плавно: при рывке кабель отсоединится (закрепить — **E**). Модуль взять в тех. помещении → вставить в разъём у сервера.
6. Сервер (большая коробка у стены) → **E**: передача. На 94% будет пауза.
7. Забрать носитель из разъёма → отнести охраннику → **E**.

## Если что-то не так

- **Персонаж не ходит / нет рук.** Не нашёлся персонаж шаблона `BP_FirstPersonCharacter`. Пришли скриншот папки `Content/FirstPerson/Blueprints`.
- **Вместо текстов надписи вроде `ST_UI` / `Task_…`.** Не нашёлся файл `Content/Localization/ST_UI.csv`. Проверь, что он есть после `git pull`.
- **Выезд не начался (нет задач).** Скрипт из шага 4 не отработал. Пришли окно с отчётом или лог: **Window → Output Log**.
