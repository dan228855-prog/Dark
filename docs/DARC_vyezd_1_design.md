# D.A.R.C. — Выезд №1: «Плановое списание»

Спроектировано по шаблону мастер-документа (разделы 44-46, 55). Длительность: 20-30 минут.

## Путь по структуре документа

**ЗАДАНИЕ НА БАЗЕ → ПОДГОТОВКА → ПРИБЫТИЕ → ИССЛЕДОВАНИЕ → ОСНОВНАЯ ЦЕЛЬ → ЦЕПОЧКА ДЕЙСТВИЙ → ФИЗИЧЕСКАЯ ПРОБЛЕМА → ИМПРОВИЗАЦИЯ → РЕЗУЛЬТАТ → ВОЗВРАЩЕНИЕ → БАЗА → ПОСЛЕДСТВИЕ**

## 1-2. Кто выдаёт задание и почему его выполнять

Задание приходит от D.A.R.C. через терминал на базе — сухим корпоративным текстом, без лица и без объяснений. Мотивация предельно простая: это их работа, за неё платят. Ровно в духе фразы с арта меню: *«Сегодня твоя задача — как обычно. Не задавай лишних вопросов»*. Глубокий сюжет тут не нужен — только тон.

## 3. Куда отправляются

Уже знакомая локация из чеклиста ассетов: КПП в лесу → старое административное здание при заброшенном радиотелескопе → служебный коридор → серверный сектор.

## 4-5. Основная цель и что искать

Официальная формулировка задания: «Восстановить архив с сервера до его планового списания». Нужно найти конкретную стойку в серверной и накопитель с архивом на ней.

## 6. Что нужно для доступа

Два независимых препятствия:
- Дверь в серверную — заперта, открывается ключ-картой или кодовой панелью (что уже есть в чеклисте).
- Сервер обесточен (готовится к списанию) — нужно вручную поднять питание через электрощит.

## 7-8. Физические взаимодействия и инструменты

Открыть дверь → пройти тёмным коридором с фонариком → открыть электрощит (отвёрткой) → вставить/провернуть рубильник → дождаться загрузки старого ПК → ввести доступ на терминале → подключить накопитель к серверу → дождаться копирования → извлечь накопитель → отнести к выходу.

## 9. Альтернативное решение

Если рубильник или предохранитель не срабатывает (или после ошибки ниже) — в соседней кладовой (класс B/C реквизит, уже есть в чеклисте) есть **переносной генератор**. Его можно притащить и запитать сервер напрямую, в обход основного щита. Дольше и тяжелее (генератор тащат вдвоём), зато не зависит от щита.

## 10-12. Ошибка → новая проблема → решение

**Ошибка:** если вставить предохранитель не по правилам (или просто поторопиться и включить рубильник раньком) — предохранитель сгорает и вырубает более широкий контур, а не только сервер.

**Новая проблема:** гаснет свет во всём коридоре, которым пришли — обратный путь идёт в темноте, только с фонариками.

**Решение:** либо вернуться к щиту и найти запасной предохранитель (в шкафу неподалёку — тоже уже в чеклисте), либо использовать генератор как альтернативу и не трогать щит второй раз.

## 13-14. Что забирают и что может потеряться

Забирают физический накопитель с архивом (уже реализован как `ACarryableItem`). Если несущий его игрок теряет сознание по пути назад (механика «духа» уже есть в `PlayerState`/`ForceDrop`) — накопитель падает на пол, и его должен поднять кто-то из команды.

## 15-16. Обратный путь и первая аномалия

Если коридор погас — обратный путь ощутимо страшнее, хотя формально ничего не изменилось.

**Первая аномалия** (маленькая, спорная, без раскрытия ИИ — как требует раздел 46): при включении сервера в папке с архивом обнаруживается **на один файл больше**, чем указано в задании. Файл не подписан номером задания и не значится в описи. Инструмент — не пугает, а сеет сомнение: обычное объяснение («забыли обновить опись», «остаток с прошлой инвентаризации») лежит на поверхности.

## 17-18. Что замечают после и последствие

На базе, в отчёте по возвращении, D.A.R.C. **сам** упоминает этот лишний файл дежурной фразой — как будто про него и так было известно, хотя в задании его не было. Игроки этого не просили и не докладывали.

**Последствие для кампании:**
- Если файл забрали — он открывает маленькую сюжетную нить на один из будущих выездов (задел под WorldMemory/RareEventManager).
- Полученный архив в любом случае даёт первое улучшение базы — открывается архивный терминал (первый шаг разблокировки базы по прогрессу).
- Если был блэкаут в коридоре — в следующем брифинге мельком упоминается «плановое обслуживание сети», без объяснений.

## Самопроверка по 9 вопросам документа (раздел 55)

1. **Интересно без сюжета?** — Да: свет, дверь, электрощит, перенос предмета — весь цикл работает как чистая механика.
2. **Интересно физически взаимодействовать?** — Да, за это отвечают уже написанные `Interactable`/`Door`/`CarryableItem`.
3. **Есть причина кооперироваться?** — Да: генератор тяжёлый (нужно 2 игрока), а несущий накопитель не может одновременно чинить щит.
4. **Естественные смешные ситуации?** — Скорее всего да: паника в темноте, спор «кто тащит генератор», кто-то уронил накопитель не вовремя.
5. **Несколько решений задачи?** — Да: щит или генератор.
6. **Ошибки создают интересные проблемы, а не раздражают?** — Блэкаут — это неудобство с понятным выходом (запасной предохранитель/генератор), не тупик.
7. **Процедурность не ломает цель?** — Расположение серверной/щита/кладовой может гулять по зданию — цель (архив) не меняется.
8. **Аномалия ощущается как часть мира?** — Да: лишний файл — это то, что могло бы существовать без всякого ИИ.
9. **Хочется ли на следующий выезд?** — Лишний файл и «плановое обслуживание» — оба задела нарочно оставлены открытыми.
