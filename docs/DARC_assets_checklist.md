# D.A.R.C. — чек-лист ассетов

Раздел 1.3 «Что нужно найти» (RU — EN), перенесён из документа автора.

**Обозначения:** ★ — нужно для вертикального среза (первый выезд), ☆ — позже / для других уровней.
`[x]` — ассет скачан, проверен и лежит в проекте. `[ ]` — ещё нет (даже если ссылка найдена).
«ссылка не сохранилась» — в исходном документе было только название страницы без адреса, найти заново.

## Лицензии — проверять перед добавлением в проект

Игра коммерческая (Steam), поэтому годятся только лицензии, разрешающие коммерческое использование.

| Источник | Что обычно | На что смотреть |
|---|---|---|
| Poly Haven, ambientCG, ShareTextures, cgbookcase | CC0 | Можно всё, указывать авторство не обязательно |
| Quaternius | CC0 | Можно всё |
| Mixamo | Бесплатно для коммерческих проектов (нужен аккаунт Adobe) | — |
| Pixabay (звуки) | Pixabay Content License | Коммерческое использование разрешено, нельзя продавать звук как есть |
| **Freesound** | **У каждого звука своя**: CC0 / CC BY / CC BY-NC | **CC BY-NC — нельзя** (некоммерческая). CC BY — можно, но автора обязательно указать в титрах. Лицензия видна справа на странице звука |
| **Fab** | Бесплатные и платные вперемешку; Standard/Personal License или CC BY | Проверить цену (бывают временно бесплатные) и тип лицензии на странице |
| **Sketchfab** | Зависит от модели (CC BY, CC BY-NC, Editorial и т.д.) | NC и Editorial — нельзя. Модели «из игры X» (рипы, фан-копии) — нельзя |
| Poliigon, RawCatalog | Часть бесплатно, часть платно | Проверить, что конкретный ассет бесплатный и лицензия коммерческая |

Для всех CC BY ассетов вести список авторов для титров (раздел «Титры» в конце файла).

## Главные дыры для вертикального среза (★ без ссылок)

Приоритет поиска, исходя из первого выезда и полноценной электросистемы:

1. **Звуки электрики** — весь блок пуст, а загадки среза завязаны на электросистему: рубильник, предохранитель, отключение/включение питания, гул ламп, мигание, искры, генератор.
2. **Звуки замков и доступа** — щелчок замка, «заперто», ключ-карта, кодовая панель, электрозамок.
3. **Звуки предметов** — удары/падения по материалам, волочение, картон/бумага, инструменты, рация.
4. **Терминал** — клавиатура, включение ЭЛТ.
5. **Модели/текстуры** — дверная рама, ворота КПП, сетка-рабица (маска), потолочные панели, окрашенный облупленный металл.
6. **Спутниковая тарелка** — текущая модель под вопросом по лицензии (см. выше).
